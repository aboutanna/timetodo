# 时间线 · 桌面侧栏（Electron）v1.5.2

把「时间线」应用做成贴靠在屏幕左侧的桌面小工具，支持两种模式：

- **悬停模式（默认）**：侧栏平时完全隐藏（不只是移出屏幕，窗口本身处于 `hide()` 状态），鼠标移到屏幕最左侧的触发条时会滑出显示；鼠标移开后短暂延迟自动收起——收起动画结束后窗口会被彻底隐藏，不会有任何残留。
- **固定模式**：点击顶部的图钉按钮 📌，侧栏常驻显示、不再自动隐藏；再次点击取消固定即可恢复悬停模式。固定状态会记住，下次启动自动生效。

托盘图标（系统状态栏）里提供「固定 / 取消固定」「显示 / 隐藏」「外观（浅色/深色/跟随系统）」「退出」菜单，因为侧栏本身不显示在任务栏 / Dock 里；点侧栏窗口自带的关闭按钮也只是把它收起，不会退出整个程序。

## v1.5.2 相对上一版的调整

1. **数据导入/导出按钮改为常驻显示**：原来悬浮在头部上方、需要鼠标靠近才淡入的按钮，现在下移一个按钮位的距离，固定在筛选行正上方的独立一行，始终可见，不再依赖 hover。
2. **导入新增「全覆盖 / 仅增加不重复」两种模式**：菜单里由原来单一的「数据导入」拆成两项——「导入（全覆盖）」保持原逻辑，用文件内容整体替换当前所有节点；「导入（仅增加不重复）」会按 `datetime + content` 比对，跳过已存在的节点，只把文件中不重复的新节点追加进来，不影响已有数据。
3. **待办项目列数新增「1 列」选项**：列数切换从 2/3/4 扩展为 1/2/3/4，单列适合只想要一份不分栏的清单的场景。
4. **时间刻度颜色再调浅一档**：上一版把纯黑色改成了深棕灰色，但对比度仍偏高、观感接近纯黑；这版进一步调浅，比日期文字（`--tm`）深、但比之前柔和不少。
5. **版本号统一为 1.5.2**（`package.json`、窗口标题、渲染进程标题与导出文件里的 `version` 字段）。

## 本轮细节调整

1. **外观切换**：托盘菜单里加了「外观」子菜单——浅色模式 / 深色模式 / 跟随系统，选择后通过 Electron 的 `nativeTheme.themeSource` 全局生效（页面原本就用 `prefers-color-scheme` 写的深色样式，不需要额外改渲染进程代码），选择会记住并在下次启动时恢复。
2. **应用图标**：背景色改成了 `#6969F5`，图形做了居中处理（水平/垂直都重新校准过）。
3. **搜索框挪到第二位**：头部工具栏顺序改为：固定按钮 → 搜索框 → 年份/月份筛选 → 收藏筛选 → 添加按钮。
4. **添加按钮只保留图标**：原来"＋ 添加节点"四个字去掉了，只留一个加号（hover 时仍有文字提示）。
5. **新增数据导入/导出**：在筛选行的正上方新增了一个小按钮，平时完全不可见，鼠标移到头部区域附近才会淡入显示；点击后弹出「数据导出 / 数据导入」两个选项。导出会把所有节点打包成一个带日期文件名的 JSON 文件直接下载；导入是选一个 JSON 文件、确认后**整体替换**当前所有节点（不是合并），已做了字段兜底和格式校验。
6. **时间文字降低了对比度**：时间刻度不再用趋近纯黑的颜色，换成了柔和一些的深棕灰色（浅色/深色模式各有一版，通过新的 `--time-c` 变量控制）。
7. **正文框回车即保存**：新建节点和编辑节点的正文textarea里，直接按 Enter 会保存，Shift+Enter 才是换行（原来的多行输入能力还在，只是触发方式变了）。
8. **项目拖拽手柄图标**：原来的六个圆点改成了两条竖线（更接近常见的"⋮⋮"抓手符号观感），拖动整个项目排序的功能不受影响。

## v1.5.1 相对上一版的调整

1. **不再使用无边框窗口**：侧栏窗口现在是普通的、带 OS 原生标题栏 / 边框的窗口（`frame: true`），只是关闭了最小化/最大化按钮、禁止拖动和缩放。
2. **收起即完全隐藏**：以前"收起"只是把窗口滑动到屏幕外，现在滑动动画结束后会调用 `hide()` 彻底隐藏窗口本身，不留任何残留（阴影、边框等）。展开时会先归位到屏幕外再 `show`，然后滑入。
3. **加宽了侧栏本体宽度**（380px → 560px）：之前的宽度会把"时间刻度在左、卡片在右"的两栏布局及 2~4 列待办网格挤变形，现在的宽度足够容纳原有布局，不会触发原设计里给窄屏准备的压缩样式。
4. **新增可打包构建**：引入了 `electron-builder`，`npm run build` 可以直接产出对应平台的安装包（Windows 用 nsis、macOS 用 dmg、Linux 用 AppImage）。
5. **版本号统一为 1.5.1**（`package.json` 与窗口标题）。

## 目录结构

```
timeline-sidebar/
├── package.json        # 含 start / build 脚本与 electron-builder 配置
├── main.js              # 主进程：窗口管理、悬停/固定逻辑、滑动动画、托盘
├── preload.js            # 预加载脚本，向渲染进程暴露最小化的 IPC API
├── renderer/
│   └── index.html        # 侧栏内容（时间线应用本体，单文件）
├── edge/
│   └── edge.html          # 贴在屏幕左边缘的隐形触发条（仍为无边框，纯功能性）
└── assets/
    └── icon.png            # 应用 / 托盘图标
```

## 开发运行

本沙箱环境无法联网安装依赖，请在你自己的电脑上执行（需要 Node.js 16+）：

```bash
cd timeline-sidebar
npm install      # 下载 Electron / electron-builder，需要联网
npm start        # 以开发模式启动侧栏
```

## 打包构建

```bash
npm run build          # 按当前系统平台打包
npm run build:mac      # 仅打 macOS dmg（需在 macOS 上运行，或配置好跨平台签名环境）
npm run build:win      # 仅打 Windows 安装包（nsis）
npm run build:linux    # 仅打 Linux AppImage
npm run pack            # 只解包不打安装包，快速验证 files/build 配置是否正确
```

产物会输出到 `dist/` 目录（已加入 `.gitignore`）。

> 提示：`electron-builder` 在打 Windows 的 `.exe` / macOS 的 `.dmg` 时通常需要对应平台的工具链（例如在 macOS 上打 Windows 包需要 `wine`），跨平台打包如果遇到报错，建议直接在目标平台上执行对应的 `build:*` 命令。图标目前只提供了一张 `assets/icon.png`，多数目标平台 electron-builder 能自动转换，如果某个平台报图标格式错误，可以另外提供该平台专用的 `.ico` / `.icns`。

## 实现说明

- **两个原生窗口**：一个是 6px 宽、贴在屏幕左边缘的透明「触发条」窗口（`edge/edge.html`，无边框，纯粹用来感知"鼠标靠近边缘"）；另一个是 560px 宽、带边框的侧栏内容窗口（`renderer/index.html`，即时间线本体）。两者都无法移动/缩放、常驻最上层、不出现在任务栏。
- **悬停展开 / 收起**：鼠标进入触发条 → 主进程先把侧栏窗口归位到屏幕外并 `showInactive()`，再用 `setBounds` 做一个 ~220ms 的缓动滑入动画；鼠标离开侧栏内容区域 → 延迟约 260ms 后开始滑出动画，动画结束后彻底 `hide()`（这段等待时间内鼠标若回来会取消收起）。
- **固定模式**：点击侧栏内的图钉按钮会通过 `ipcRenderer` 通知主进程切换固定状态；固定后侧栏保持展开、不再响应鼠标离开事件，触发条窗口也会被隐藏（不需要了）。固定状态写入 `app.getPath('userData')/sidebar-config.json`，下次启动会读取并恢复。
- **时间线本体没有被拆开重写**：`renderer/index.html` 就是原来的单文件时间线应用（收藏、月份筛选、搜索、项目拖拽排序等功能都保留），只新增了一小段与 Electron 的对接代码（在 `window.sidebarAPI` 存在时才生效），所以这份 HTML 单独用浏览器打开也完全可以正常使用，不依赖 Electron。
- **数据存储**：待办数据仍然存在浏览器的 `localStorage`（key 为 `tl-v4`），Electron 里对应该应用的 `userData` 分区，和普通网页的存储机制一样，卸载重装前都会保留。

## 可能需要按你的系统调整的地方

- `main.js` 顶部的 `SIDEBAR_WIDTH`（默认 560）、`EDGE_WIDTH`（默认 6）、`ANIM_MS`（动画时长）、`AUTO_HIDE_DELAY`（悬停后自动收起的延迟）都是简单常量，可以直接改。
- 目前固定在主显示器（`screen.getPrimaryDisplay()`），多屏环境如果想贴在其他屏幕左边，需要改 `workArea()` 里取的 display。
- `package.json` 里的 `build.appId` / `productName` 是占位内容，正式分发前建议换成你自己的标识。
