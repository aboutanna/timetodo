# 时间线 · 桌面侧栏（Electron）v1.5.3

一个贴靠在屏幕左侧的桌面小工具：按时间顺序记录事件节点，每个节点下可以挂一份多列待办清单。全部数据存在本地（`localStorage`），不联网、不注册账号。

## 使用模式

- **悬停模式（默认）**：侧栏平时完全隐藏（不是移出屏幕，窗口本身处于 `hide()` 状态），鼠标移到屏幕最左侧的触发条时会滑出显示；鼠标移开后短暂延迟自动收起，动画结束后窗口彻底隐藏，不留残留。
- **固定模式**：点击悬浮在页面顶部的图钉按钮，侧栏常驻显示、不再自动隐藏；再次点击取消固定即可恢复悬停模式。固定状态会记住，下次启动自动生效。

侧栏本身不出现在任务栏 / Dock 里，所有全局操作都在**系统托盘图标**的右键菜单里：固定 / 取消固定、显示 / 隐藏、外观（浅色 / 深色 / 跟随系统）、数据（导出、导入-全覆盖、导入-仅增加不重复）、退出。

## 功能一览

- **时间线记录**：新增 / 编辑 / 删除节点，每条记录一个时间点 + 一段正文，支持收藏标记。
- **日期分组显示**：每天最早的一条节点上会突出显示大号的「日」数字作为分组标题，同一天其余节点只显示时间（到分钟），减少重复信息；页面顶部还有一个悬浮小标签，滚动时会实时提示当前看到的是哪一年哪一月，停止滚动后自动淡出。
- **多列待办**：每个节点下的待办支持 1/2/3/4 列布局，可跨列拖拽排序，列可以单独命名。
- **搜索 / 筛选**：搜索框和年月筛选默认收起为图标按钮，点击展开，避免头部拥挤；筛选生效时图标会高亮提示。
- **收藏筛选**：一键只看收藏的节点。
- **数据导入 / 导出**：从托盘菜单触发。导出会把所有节点打包成带日期文件名的 JSON 直接下载；导入弹出系统原生的文件选择框，支持「全覆盖」（整体替换当前数据）和「仅增加不重复」（按 `datetime + content` 去重后追加）两种模式。
- **深浅色模式**：跟随系统 `prefers-color-scheme`，也可以在托盘菜单里手动固定为浅色 / 深色。
- **视觉风格**：整体配色、按钮形状、圆角等参照 Apple 系统控件的观感（systemBlue 强调色、圆形图标按钮、分段控件、胶囊输入框等）。

## 目录结构

```
timeline-sidebar/
├── package.json        # 含 start / build 脚本与 electron-builder 配置
├── main.js              # 主进程：窗口管理、悬停/固定逻辑、滑动动画、托盘、数据导入的原生文件对话框
├── preload.js            # 预加载脚本，向渲染进程暴露最小化的 IPC API
├── renderer/
│   └── index.html        # 侧栏内容（时间线应用本体，单文件）
├── edge/
│   └── edge.html          # 贴在屏幕左边缘的隐形触发条（无边框，纯功能性）
└── assets/
    └── icon.png            # 应用 / 托盘图标
```

## 开发运行

需要 Node.js 16+，且本机能联网安装依赖：

```bash
cd timeline-sidebar
npm install      # 下载 Electron / electron-builder
npm start        # 以开发模式启动侧栏
```

## 打包构建

```bash
npm run build          # 按当前系统平台打包
npm run build:mac      # 仅打 macOS dmg（需在 macOS 上运行，或配置好跨平台签名环境）
npm run build:win      # 仅打 Windows 安装包（nsis）
npm run build:linux    # 仅打 Linux AppImage
npm run pack            # 只解包不打安装包，快速验证 files/build 配置是否正确
```

产物会输出到 `dist/` 目录（已加入 `.gitignore`）。

> 提示：`electron-builder` 在打 Windows 的 `.exe` / macOS 的 `.dmg` 时通常需要对应平台的工具链（例如在 macOS 上打 Windows 包需要 `wine`），跨平台打包如果遇到报错，建议直接在目标平台上执行对应的 `build:*` 命令。图标目前只提供了一张 `assets/icon.png`，多数目标平台 electron-builder 能自动转换，如果某个平台报图标格式错误，可以另外提供该平台专用的 `.ico` / `.icns`。

## 实现说明

- **两个原生窗口**：一个是 6px 宽、贴在屏幕左边缘的透明「触发条」窗口（`edge/edge.html`，无边框，纯粹用来感知"鼠标靠近边缘"）；另一个是 560px 宽、带边框的侧栏内容窗口（`renderer/index.html`，即时间线本体）。两者都无法移动/缩放、常驻最上层、不出现在任务栏。
- **悬停展开 / 收起**：鼠标进入触发条 → 主进程先把侧栏窗口归位到屏幕外并 `showInactive()`，再用 `setBounds` 做一个 ~220ms 的缓动滑入动画；鼠标离开侧栏内容区域 → 延迟约 260ms 后开始滑出动画，动画结束后彻底 `hide()`（这段等待时间内鼠标若回来会取消收起）。
- **固定模式**：点击悬浮在页面顶部的图钉按钮会通过 `ipcRenderer` 通知主进程切换固定状态；固定后侧栏保持展开、不再响应鼠标离开事件，触发条窗口也会被隐藏（不需要了）。固定状态写入 `app.getPath('userData')/sidebar-config.json`，下次启动会读取并恢复。
- **时间线本体没有被拆开重写**：`renderer/index.html` 就是一份完整独立的单文件时间线应用（收藏、筛选、搜索、项目拖拽排序等功能都在里面），只额外挂了一小段与 Electron 的对接代码（在 `window.sidebarAPI` 存在时才生效），所以这份 HTML 单独用浏览器打开也能正常使用，不依赖 Electron，只是没有托盘菜单和贴边隐藏这些桌面特性。
- **数据导入走原生对话框**：数据导入由托盘菜单触发，Chromium 不允许通过代码模拟点击网页里的 `<input type="file">` 来弹出文件选择框（除非是页面内真实的用户手势），托盘点击不满足这个条件；因此文件选择改为在主进程用 `dialog.showOpenDialog` 完成，读取文件内容后再通过 IPC 传给渲染进程解析。
- **数据存储**：待办数据存在浏览器的 `localStorage`（key 为 `tl-v4`），Electron 里对应该应用的 `userData` 分区，和普通网页的存储机制一样，卸载重装前都会保留。

## 可能需要按你的系统调整的地方

- `main.js` 顶部的 `SIDEBAR_WIDTH`（默认 560）、`EDGE_WIDTH`（默认 6）、`ANIM_MS`（动画时长）、`AUTO_HIDE_DELAY`（悬停后自动收起的延迟）都是简单常量，可以直接改。
- 目前固定在主显示器（`screen.getPrimaryDisplay()`），多屏环境如果想贴在其他屏幕左边，需要改 `workArea()` 里取的 display。
- `package.json` 里的 `build.appId` / `productName` 是占位内容，正式分发前建议换成你自己的标识。
